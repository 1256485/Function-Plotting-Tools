数学函数绘图工具

试卷平面直角坐标系 · 多曲线 · 标记点 · 高清导出

使用说明 · 输入格式

语法要点：乘号用 *（如 2*x），幂用 ^ 或 **（如 x^2、x**2）；隐式方程直接写等式（x^2+y^2=1）；函数名可任意嵌套复合。

① 显式函数 y=f(x)

在表达式框直接填右边部分（可省去 y=），类型选 y=f(x)。

二次 / 多项式x**2-2*x、x**3-3*x+1
幂函数x**3、x**0.5（即√x）、sqrt(x)
指数函数2**x、exp(x)（即 eˣ）、e**(-x)
对数函数ln(x)（自然对数）、lg(x)（常用对数）、log2(x)；
任意底 a：ln(x)/ln(a)（如 log₂x 写作 ln(x)/ln(2)）
三角函数sin(x)、cos(x)、tan(x)、cot(x)、sec(x)、csc(x)
反三角arcsin(x)、arccos(x)、arctan(x)
双曲 / 反双曲sinh(x)、cosh(x)、tanh(x)、arcsinh(x)、arctanh(x)
复合函数ln(sin(x)+2)、exp(x)*cos(x)、sqrt(abs(x))、sin(2*x)+cos(3*x)

② 隐式方程 F(x,y)=0（画椭圆、圆、双曲线）

类型选 F(x,y)=0，直接写等式即可（也兼容 x^2+y^2-1 这种 F=0 形式）。

圆 x²+y²=r²x^2+y^2=4（半径 2）
圆 (x−a)²+(y−b)²=r²(x-2)^2+(y-1)^2=4
椭圆 x²/a²+y²/b²=1x^2/9+y^2/4=1（长轴 3、短轴 2）
双曲线 x²/a²−y²/b²=1x^2/4-y^2/9=1

③ 定义域

“坐标系”面板的 x 最小 / x 最大 控制整张图范围；每条曲线下方可单独填 x 定义域 限定该曲线的绘制区间，留空 = 整条 x 轴。

④ 标记点

每行填 x、y、标签、点颜色；标签支持下标/上标：F_1 → F₁、A^2 → A²、多位用花括号 F_{in}。
标签位置自由控制：距离 = 距点的像素，角度 = 偏转角度（0°=正右、90°=正上、逆时针方向）， 任意组合可让标签放到点周围任何位置以避开曲线。

⑤ 导出

PNG：3000px 高清位图；SVG：矢量图（Word 2016+ 可直接插入，放大不失真）；打印 / 导出矢量 PDF：在打印对话框选“另存为 PDF”。

曲线 / 方程

类型 y=f(x) 显式函数，或 F(x,y)=0 隐式方程（椭圆、圆、双曲线）。
隐式方程可直接写等式：x^2+y^2=1、x^2/9+y^2/4=1（也兼容 x^2+y^2-1 形式）。
支持函数：sin cos tan cot sec csc arcsin arccos arctan / sinh cosh tanh arcsinh arccosh arctanh / sqrt exp ln lg log log2 abs / 常量 pi e，可任意复合如 ln(sin(x)+2)。
注意：乘用 *（如 2*x），幂可用 ^ 或 **（如 x^2、x**2）。

标记点

格式：x、y、标签、点颜色。标签支持下标/上标：F_1、A^2、F_{in}；标签位置由“距离 + 角度”自由控制（距离为距点像素，角度 0°=右、90°=上、逆时针）。
